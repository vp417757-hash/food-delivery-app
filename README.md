# food-delivery-app
🍔 Food Delivery App UI Design
✨ Project Overview

This is a Food Delivery App UI Design created using Figma. The application provides a simple and attractive interface for users to explore restaurants, browse food items, add items to the cart, make payments, and track their orders.

🎯 Objective

The main objective of this project is to design a user-friendly food delivery application with a clean and modern interface that makes ordering food easy, quick, and convenient.
